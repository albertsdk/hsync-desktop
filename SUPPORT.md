# Support

## How to get help

- **[Documentation](docs/README.md)** — usage guide and related project links.
- **[HSYNC Client issues](https://github.com/albertsdk/hsync-client/issues)** — for issues with the underlying sync engine.
- **[GitHub Issues](https://github.com/albertsdk/hsync-desktop/issues)** — bug reports and feature requests for the desktop GUI.
- **[Security Policy](SECURITY.md)** — how to report security vulnerabilities privately.

## Before asking for help

1. Check the [documentation](docs/README.md), the [usage guide](docs/sync-basics.md)
   and the [troubleshooting guide](docs/troubleshooting.md).
2. Reproduce the problem with the CLI client, to tell a GUI issue from an engine
   issue:

   ```bash
   hsync server server.example.com -b mybucket -p /path -v
   ```

3. Include the log excerpt, your operating system and the app version
   (**Help → About**) in the report.

## 💚 Solo project

HSYNC is a passion project maintained in spare time by volunteers. Feature requests, bug reports, and pull requests are reviewed as soon as possible, but response times may vary. Thank you for your patience and support!
